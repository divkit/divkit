How to read this comparison

The table shows the median of run medians for A and B. Δ = (B / A − 1) × 100%. Iterations within a run are not treated as independent test runs.

The interval is an approximate bootstrap estimate over whole runs, without correction for multiple metric comparisons. The primary metric is Div.TotalFirstMs. An interval does not rule out systematic effects from temperature, background activity or execution order. “No clear change” does not imply equal performance.

The report compares scalar timing metrics from JSON. Per-frame sampledMetrics distributions and Perfetto traces are retained with the source results. The first draw does not mean that network images have finished loading.
